# The Greater Good?: Tradeoffs Between Social Connection and Status in Decision-Making Scenarios

## Author
Jonah Dratfield

## Project Overview
Strong social relationships have consistently emerged as predictors of well-being in the psychological literature. However, research has not distinguished between the intrinsic social value derived from these relationships and the status derived from them. We constructed the novel Relationship Orientation Scale to explore this gap, utilizing binary decision-making scenarios in which individuals were forced to pit these two goods against one another. Across two studies, we found that individuals displayed a significant, but by no means universal, preference for intrinsically rewarding social relationships. We found also that social media use and comparison orientation were negative predictors of relationship orientation, whereas agreeableness was a positive predictor. Notably, exploratory analyses revealed no association between relationship orientation and flourishing.


## Repository Contents
- `data/` — Survey response files from study participants
- `code/` — R scripts used for data cleaning and analysis
- `output/` — Figures and visualizations generated from the analysis
- `docs/` — Thesis PDF

## Data
Data were collected via Qualtrics survey administered to students enrolled 
in introductory psychology courses at Brooklyn College. Data are restricted 
and not publicly available due to IRB and participant confidentiality 
requirements. Raw data files have been de-identified.

## Code / Analysis
Analysis was conducted in R. Scripts in the `code/` folder include data 
cleaning, statistical analysis, and figure generation.
